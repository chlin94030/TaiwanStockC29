Alpha Radar PRO V30 Strategy Lab｜完整資訊與持續驗效

選股儀表板：完整推薦總表＋重點卡片；個股圖表、基本面、法人資券與資金配置。
模型測試驗證：驗效總覽／因子研究／策略競賽／研究報告。
可啟用「持續研究」，自動分批建歷史資料及搜尋候選；進度可暫停續跑。
現有快照及固定先驗尚未驗證投資績效，不是最佳權重或正式冠軍。
近期連續資料需足夠暖機、24個月訓練、至少315個交易日開發期及保留期；保留期不選型、檢查一次鎖定，品質及多重試驗校正全過才採用。

本版為獨立產品，不需要匯入其他專案資料。

1. 開啟「選股儀表板」，直接顯示有日期的真實市場快照與推薦原因。
2. 背景自動更新整批行情、營收、財報與估值；歷史K線逐步補齊。
3. 盤中預設每5秒刷新報價區；畫面保留實際成交時間，更新失敗不偽裝成新成交。
4. 先讀入選理由與風險，再查看個股圖表；技術價位尚未完成時維持觀察。
5. 「模型測試驗證」可看資料檢核、權重及下載研究報告。

手機：使用同層檔案上傳包，解壓後全部檔案都在同一層。
alpharadar_core.zip 不要再解壓，上傳後由程式自動讀取。
Streamlit入口 app.py；本機執行 python -m streamlit run app.py。
首次安裝套件需網路，但使用者不必下載多年歷史資料才開始選股。

0050可以不配置。單股與族群上限、風險預算都在配置展開區。
技術買區至少需60根真實OHLC；只有收盤序列時先顯示折線，不編造K線。
上市／上櫃近期價量會輪流補齊，已取得資料先接圖表；主力分點仍未接入。

5秒代表刷新排程，仍受上游回應、網路與實際成交頻率影響。
獨立模型的投資績效仍須歷史時點驗證，沒有沿用舊模型報酬。
系統不自動下單。
