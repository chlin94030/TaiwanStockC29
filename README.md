## 開啟即用

建議Python 3.12，安裝後執行：

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

第一次便讀取隨附的真實啟動快照；網路更新、財報與歷史K線補齊在背景進行。這是伺服器上的自動更新，使用者不必手動下載資料。盤後停止成交報價請求，保留最近推薦。長期連續更新需部署環境保持運行。

手機部署仍使用同層檔案包，全部上傳同一層即可。核心ZIP保持原樣，由程式載入。來源歷史文件只供追溯；目前產品流程以本文件為準。

## 模型

快照初選使用實際營收、財報淨利率、估值、相對強勢、趨勢、法人、融資、風險、流動性及收盤強度，分短中長線配置固定先驗。估值與品質有足夠同業時依產業比較。歷史未齊或因子未取得時保持中性50分，涵蓋率至少50%才列初選觀察，並非立即可買。

不把舊研究模型的報酬當作本模型績效。歷史時點基本面、除權息、名冊、成本、跨市場與價位規則尚需完整回測；報告明列待驗證，沒有預設勝率或年化報酬。

## 5秒更新

盤中預設每5秒重繪報價區。伺服器共享非同步報價，避免每位使用者重複請求。網路較慢時畫面仍顯示前次資料，不阻塞整頁；保留真實成交時間，失敗不把舊成交重新標成新成交。5秒是排程，不保證上游每5秒回應或每檔有新成交。

推薦分數來自較慢的選股因子；成交報價與執行狀態分開。可用海外情境時，最高12%僅調整盤中執行排序。未成交／逾時／非盤中時不顯示可布局。

## 價格與配置

歷史至少60根真實OHLC，且行情日期相符時，才計算買進區、防守與2R。尚未取得時維持「價格待K線確認」；僅有收盤序列時先顯示折線，完整K線與指標漸進補齊。上櫃完整歷史K線目前尚未接入，會明示缺少。

0050為選用，可為0%。配置預設單股10%、同族群25%、每檔至防守價風險0.5%；目標試算須自行扣除既有部位，不自動下單。法人是已公布日資料；大戶及主力分點尚未接入，不用其他數字替代。
